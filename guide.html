拾帧工具能做什么？

一款专业的在线模拟手写稿件工具，本地版具备以下核心功能：

  • ⚡️ 高效转换：一寸光阴一寸金，不必将光阴浪费在枯燥抄写任务上。
  • 📝 文档转手写：一键将上传文档转换为逼真的手写稿图片，支持多种纸张和字体。
  • 🖼️ 高清实拍效果：提供程序化生成的高清实拍纸张纹理（稿纸、信纸、草稿纸、牛皮纸）。
  • 🖨️ 专业打印支持：A4 / B5 / A3 纵横 600dpi 超高清输出，完美支持线下打印。
  • ✍️ 多种字体选择：40+ 手写风格字体，覆盖中文、繁体、日文、韩文与英文。
  • 🤖 真实细节模拟：文字位置凌乱度、字体笔画凌乱度、基线波动、墨色浓淡、随机勾画涂改。
  • 🔍 便捷预览功能：转换前提供完整预览，所见即所得，且预览与下载同源一致。

常见问题

Q：为什么我的文件无法上传？

A：请确保上传的是 .doc（不推荐，老格式有概率报错）或 .docx（推荐）格式的 Word 文档，且 Word 里不要包含图片等非文字内容。本地版对文件大小无 1MB 硬限制，但超大文件解析会变慢。

Q：下载时输出图片的数量有上限吗？

A：由于 600dpi 高清图片体积大，默认单次输出上限为 12 页；可在「输出设置 → 单次输出上限」改为 3 / 5 / 8 / 12 / 20 页。

Q：输出图片有水印吗？

A：全程无水印。预览为 100dpi、下载为 600dpi 高清，均不带任何水印字样或图标。

Q：为什么文件中部分空格显示不出来？

A：有些文件中的空格是不可见字符（不换行空格、零宽空格），本地版已自动归一化；如仍有异常，请自行调整为 tab 制表符或普通空格键。

Q：为什么文件中部分生僻字显示不出来？

A：说明所选字体不含该生僻字。默认会回退到系统字体显示；勾选「缺字显示为空格」后，该字会按官网行为显示为空格，此时请更换字体。

Q：如何选择纸张类型？

A：需要实拍图选「实拍系列」；需要打印选「可打印系列」（A4 / B5 / A3 纵向或横向，600dpi）。稿纸类为一格一字，20×20 = 400 字/页。

Q：我想打印手写稿，怎么办？

A：纸张类型选「可打印」系列 → 下载高清图片或 PDF → 去线下打印店打印即可；打印墨水浓则效果更佳。PDF 已按纸张实际毫米尺寸设置页面大小，可直接按 100% 打印。

Q：下载后找不到文件怎么办？

A：浏览器按 Ctrl+J 打开下载记录；手机端在浏览器「我的 → 下载」里查看。

Q：超级DIY 的注意事项？

A：1，框选位置尽可能贴近文字。2，尽可能框住段落而不是整个文章。3，注意不要框选到边界或者表格边界线。4，填表格模式需设置正确的行列数。5，自动扩页上限为 10 页，需要更多页请分多次操作。

Q：拾帧工具如何保护用户隐私？

A：本地版所有解析与生成都在浏览器内完成，上传内容、生成文件与图片不会上传到任何服务器，也不做任何形式的备份。

如何上传文件

  1. 点击「上传文件 → 选择文件」，选择 .docx 或 .pdf / 图片 / .txt。图片会自动进行本地 OCR 识别。
  2. 上传成功后，文件名显示在按钮下方。解析出的文字同步填入「仅输入文字」框，可直接修改。
  3. 如需更换文件，点击文件名右侧的「×」清除当前文件，然后重新上传。
  4. 也可以直接用「仅输入文字」粘贴文字，或用「AI帮写 | 润色」生成文章内容。

如何设置转换参数

  1. 选择字体：从下拉菜单中选择喜欢的手写字体样式，45 款按我的手写 / 中文 / 真实笔迹 / 繁体日韩 / 其他语言分组。默认选中「平方洒脱体（马善政楷书）」——纤细连笔的硬笔行楷，最接近官网示例的学生手写效果；想用自己的字，切到「我的手写」里的 zx 并按第 3 节扩充字库。
  2. 纸张背景：选择手写稿背景，可以是实拍稿纸或白底可供打印的类型；也可上传自定义背景图片。
  3. 随机勾画涂改概率：拖动滑块调整勾画涂改率，推荐 3%（更接近真实手写）。
  4. 文字位置凌乱度：在高级设置中调整整齐程度，推荐 10%；字体笔画凌乱度推荐 5%。
  5. 其他：字号、行距、字间距、页边距、字迹颜色、涂改笔色、段首缩进、两端对齐、页码、随机种子。

zx（我的手写 · 真迹字库）

  1. 字体下拉第一组「我的手写」里选 zx（需手动切换，出厂默认是更通用的平方洒脱体）。照片里抠出的真迹共 27 字 / 62 个书写变体，同一个字随机换写法，每次落笔还带独立的微小角度与大小变化；用「ZX 真迹字库扩充」自己写进去的字（含符号）同样按真迹位图绘制。
  2. 官方图集里的汉字直接贴真迹位图；数字、字母、括号、√、∩ 等符号源自作业照片的粗笔连写，缩到正文小字号会糊成一团，故改用 zx.ttf 的干净轮廓补全（同样的手写字形与逐字形变，但清晰不粘连）。照片里没出现过的汉字也由 zx.ttf 补全：基底是最接近硬笔行楷的马善政楷书（原志莽行书是毛笔草书，与真迹差距最大），再按照片实测参数施加右倾 6°、横向微放 1.02、左紧右松与中宫收紧的非线性字形变换、部件级错位 9~16.5/1000em、逐点手抖 4.2~7.1/1000em（逐字随机，不再全字库一个固定值），覆盖 7000+ 常用字。
  3. 高级设置里新增「书写自然度 · 行内节奏」（默认 45%）：字高、基线、倾角、墨量随行内书写位置连续变化，行首写得慢字略大而正、行尾加快字略小而飘，一笔写完墨变淡；并带出极细的行楷牵丝。调到 0% 即回到印刷体式排列。
  4. 高级设置里新增「笔压墨感 · 逐字形变」（默认 45%）：每个字先画到离屏图层，按 12 条水平条带做独立相位的手腕抖动再贴回，同一个字在不同位置、不同种子下笔画走向都不同，消除「同一个字每次一模一样」的电脑字体感；同时叠加洇墨外晕、飞白断笔、细/中/重三档笔压、整行斜率上飘或下坠、词组字距呼吸、标点收紧与收笔出锋。调到 0% 即只剩纯净字形。
  5. 想把更多汉字换成自己的真迹：点顶部「ZX 真迹字库扩充」，留空时按 643 个高频字自动分成 7 页字帖（有「上一页 / 下一页」）；也可直接粘贴自己的文章，字帖就按文章里的字排布。每页重复「打印 → 手写 → 拍照上传 → 点四角 → 切格 → 入库」，字库持续累积，同一字拍得越多写法越多。样本存本机浏览器，可导出 JSON 备份。
  6. 真迹字与补全字共用同一套排版坐标系与随机种子，100dpi 预览和 600dpi 下载的笔迹、抖动、涂改位置逐字一致。

预览与下载

  1. 设置完参数后点击「点击预览」查看转换效果（预览 100dpi 压缩图，下载 600dpi 高清）。参数变化会自动刷新预览。
  2. 预览支持单页 / 全部页切换、页码跳转、35%—100% 缩放。
  3. 导出格式支持 ZIP（多页 PNG 打包）、PDF（可直接打印）、PNG（当前预览页单张）。
  4. 下载文件为高清无水印版本。同一随机种子下，预览与下载的笔迹、涂改位置完全一致。

启动与故障排查

  1. 打包版：双击 手写模拟器ZX.exe，出现黑色状态窗口后浏览器自动打开首页；关掉该窗口即退出。首次启动解压字体组件约 2~5 秒，端口 8765 被占用时自动顺延。
  2. 源码版：双击 start.bat 启动本地服务并打开首页（需要本机 Python）。请勿直接双击 index.html（file:// 协议下浏览器会拦截字体与 PDF/OCR 组件）。
  3. 首次进入需加载约 40MB 手写字体，状态栏会显示加载进度，稍等即可。
  4. 图片 OCR 使用中英文语言包，首次识别需初始化引擎，约数秒。
